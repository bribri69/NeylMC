# **⛏️ NeylMC ModPack**

_A modpack optimized to run on laptops.\
Focused on an immersive multiplayer experience._

**✨ Features :**\
**Improved performance :** Rendering optimization and reduced lag.\
**Visuals :** Dynamic lighting added for greater immersion.\
**Minimap :** Because it makes navigating much easier.\
**Proximity Chat :** For a more immersive multiplayer experience.\
**Quality of Life :** JEI, AppleSkin, shulkerboxtools and more. The little details that make all the difference !
